# techstack

Environment configuration and system setup for my AI/ML development environment.

## Ecosystem Repositories

- **[`blks`](https://github.com/mattkellymt/blks)**: Lightweight PyTorch building blocks package (available on PyPI).
- **[`experiments`](https://github.com/mattkellymt/experiments)**: Machine learning research implementations and network architecture explorations.
- **[`techstack`](https://github.com/mattkellymt/techstack)**: Fedora system setup scripts and environment configuration.

## Setup

```bash
git clone https://github.com/mattkellymt/techstack.git
cd techstack && fedora/setup
```
